# Sotto 0.10.0

> Superseded by [v0.10.1](https://github.com/getsotto/sotto/releases/tag/v0.10.1), which corrects CLI signature verification for the official installers.

## Release Notes — 2026-09-14 – 2026-11-01

### Sotto Cloud
- **Personal plans** — Start a monthly or annual Sotto Cloud plan, manage billing from your account, and view founding prices when eligible. Checkout displays applicable tax. (#492, #570, #602, #766)
- **Data portability** — Export an encrypted copy of your Cloud data for offline recovery. (#520)

### CLI and automation
- **Project tasks** — Declare tasks in `sotto.toml`, list them with `sotto task ls`, and use approval-gated local agent workflows. (#618, #621, #624, #643)
- **Structured organisation output** — Get JSON output for organisation members and see machine-token expiry in `sotto token ls --json`. (#533, #546)

### Sharing
- **Browser share links** — Create and copy share links from the web app, with clearer recipient recovery when a link cannot be opened. (#577, #599)
