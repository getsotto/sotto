# Sotto 0.11.0

## Release Notes: 2026-11-24

### CI and machine tokens
- **Faster machine fetches**: A machine token now fetches its grant and secrets in one request, from one consistent snapshot, and asks for gzip, so large environments arrive in fewer round trips. (#845)
- **Faster TLS on Linux**: The CLI uses rustls with the system certificate roots on Linux, so a run no longer parses the whole certificate bundle through OpenSSL. Private certificate authorities and `SSL_CERT_FILE` keep working. (#859)
- **Quicker first response from the hosted edge**: The edge raises TCP's initial congestion window, so a mid-sized response leaves in one flight. Deployments that run the bundled Caddy image get this with the new compose file, which grants the container `NET_ADMIN`; the capability is dropped before Caddy starts. (#860)

### Terminal interface
- **Navigation**: Shift+Tab steps backwards through environments, Page Up and Page Down work in version history, Ctrl+U clears the search, and `R` reloads local secrets.

### Web app
- **Shared secrets and unlock**: Show or hide the passphrase a recipient types, and show or hide the Secret Key on unlock. Escape hides a revealed secret.
- **Billing and exports**: Payer-transfer response deadlines show a time and time zone, discovery failures offer an in-place retry, and preparing an encrypted export shows progress.

### Security and operations
- **Dependency advisories**: Moved past advisories in `url`, `rustix`, `vite`, `rustls`, `rustls-webpki` and the QUIC crates, and shipped the patched bundled SQLite.
- **MCP server**: Rejects invalid JSON-RPC versions and non-object tool arguments, negotiates a protocol version it implements, and no longer depends on the rmcp SDK.
- **Backups**: A failed backup leaves a marker in the bucket, the freshness alarm closes only on a backup the cron job took, and `deploy/upgrade.sh` moves the image pin and pulls the checkout in one command.

### Upgrading
- No database migrations and no change to the wire format, token format or store.
- Self-hosted deployments: pull the new `deploy/docker-compose.prod.yml` together with the new image, because the edge image now expects `NET_ADMIN`. Delete `cap_add` from the compose file to keep the kernel's default window.
