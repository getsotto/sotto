# Sotto 0.11.1

## Release Notes: 2026-11-25

### Search and the website
- **Four new guides**: New guides cover Sotto as an open-source secret manager, a CLI secret manager, a dotenv alternative and a secret manager for CI/CD pipelines. Like the existing guides, each one is prerendered, so search engines and visitors without JavaScript get the full page. (#902)
- **Clearer search listings**: The homepage title, description, social preview images and structured data now describe Sotto as an open-source encrypted secret manager for developers, and the landing page matches what crawlers see. (#902)
- **Private pages stay out of search**: App, share link, sign-in, account and API paths now send `X-Robots-Tag: noindex, nofollow`, so they stay out of search indexes even when someone links to them publicly. `/index.html` now redirects permanently to `/`. (#902)
- **llms.txt**: The site publishes `/llms.txt`, a plain-text summary of Sotto and its guides for AI assistants, next to the sitemap. (#902)
- **Lighter page loads**: The edge compresses responses with zstd where the browser supports it and falls back to gzip, and brand images and icons are cached for a day instead of being revalidated on every load. (#902)

### CLI
- **Task approvals as JSON**: `sotto task approvals --json` prints the stored approvals as a JSON array, and `--env` narrows it to one environment. An empty result prints `[]`. (#883)
- **Config errors name the file**: When a `sotto.toml` cannot be read, the error now says which file it was. (#852)

### Documentation
- **Listing secret names**: The README, in all five languages, now explains `sotto ls`, its plaintext and JSON output, and how to choose an environment. (#835)

### Upgrading
- No database migrations and no change to the wire format, token format or store.
- Self-hosted deployments: no `.env` or compose file changes. The new edge rules ship inside the `sotto-web` image, so pulling the new image is enough. Like the sitemap, `llms.txt` uses the origin set by `SOTTO_PUBLIC_URL` when the web image is built.
